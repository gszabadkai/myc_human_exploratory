## 2. THE PRE-SPECIFICATION - fixed before the numbers, and it binds

All of this is in the script header. It is repeated here only because a
decision is being taken against it.

**The model.** `BBC3 ~ MYC + OXPHOS` on Blom normal scores, fitted separately
per cohort, never pooled.

```
beta1 = partial MYC    -> BBC3 at fixed OXPHOS    PREDICTED NEGATIVE
beta2 = partial OXPHOS -> BBC3 at fixed MYC       PREDICTED POSITIVE
```

**The three readings, fixed 2026-09-07 before stage 2 ran:**

- **(i) SUPPORTED** - `beta1` negative with interval excluding zero on FELSHER
  **and** regulon **and** dose, after `PROLIF_DISJOINT` + purity, pooled **and**
  within Luminal. Written as a **modest** effect.
- **(ii) NOT TRANSFERRED** - `beta1 -> 0` on adjustment where it was **not**
  clearly present unadjusted **on the same samples**. A reportable negative.
- **(iii) AMBIGUOUS** - `beta1 -> 0` on adjustment **having been present
  unadjusted on the same samples**. Proliferation may be a confounder **or a
  mediator** (`MYC -> PI3K/AKT -> FOXO3 nuclear exclusion -> BBC3`) and this
  model cannot separate them. **Under (iii) the FOXO3 mediation leg is the
  tiebreaker and its gate opens on the UNADJUSTED `beta1`, not the adjusted
  one.**

(ii) and (iii) are separated by one computed fact - whether the unadjusted
effect was present on the sample set the adjusted fit uses. That is why the
ladder runs on **one fixed subset per cohort**: TCGA n = 1,020 purity-complete,
SCAN-B n = 3,207. Comparing across different n would confound the covariate
with the sample set (E16 section 6's discipline).

**The D2 rule**, also fixed in advance: the claim requires `beta1 < 0` on all
three claim estimators in both cohorts, **sign only**. `M_b` carries the widest
SE and is **not** dropped on effect size - that power table was built for an
interaction term and a main effect needs roughly a quarter of the n.

## 3. THE DECISION - this is what the session stopped on

**The classifier fired `(ii) NOT TRANSFERRED` on both rulers, and the stage 3
gate is CLOSED.** That is a mechanically correct application of the rules as
written. Two facts sit beside it and neither is a reason to rewrite the rule.

**(a) The observed pattern is not attenuation. It is SIGN REVERSAL.** On the
signature estimator `beta1` goes from `-0.200` to `+0.136` in TCGA and from
`-0.060` to `+0.106` in SCAN-B, with intervals excluding zero **on the positive
side**. Reading (ii) describes `beta1 -> 0`; this is past zero and out the other
side.

**(b) (iii) was ruled out by a single borderline cell.** `reading_iii` requires
the unadjusted effect present in **all six** cells. It is present in **five**.
The one that fails is **TCGA dose, unadjusted, at n = 1,020: `-0.018`
`[-0.077, +0.041]`** - it spans zero. Had that interval been slightly narrower,
(iii) would have fired and the gate would be **open on the unadjusted `beta1`**,
which stage 1 already put below zero in 12 of 12 cells.

**And the substantive ambiguity (iii) exists for is live whichever label
fired**: `PROLIF_DISJOINT` does essentially all the work, and if proliferation
is a **mediator** then adjusting for it destroys the effect being tested.

### The three options, and none is picked here

1. **Accept (ii) as given.** Write the reportable negative, gate stays closed,
   no stage 3.
2. **Rule that (iii) applies on the substance** - sign reversal after an effect
   clearly present unadjusted in 5 of 6 cells. That opens the gate on the
   **unadjusted** `beta1` and licenses stage 3 (FOXO3 regulon mediation) as the
   tiebreaker.
3. **Neither** - the more interesting object is now **`BCL2L1`**, which was the
   specificity control and is the only gene in the roster with a concordant
   negative `beta1`. See section 4.

**Do not adjudicate this with a tie-break invented after the fact.** If option 2
is taken, it is taken as a stated judgement about a borderline cell, recorded as
such in the note, and not as the rule having fired.

## 5. TWO FINDINGS THAT TRAVEL WHATEVER IS DECIDED

**5.1 The marginal correction, and it is a deliverable.** `rho(BBC3, MYC)` is
**negative in 10 of 10** estimator-by-cohort cells on Spearman, and Blom-Pearson
agrees (largest gap 0.043). **Any manuscript sentence saying `BBC3` is
"uncorrelated with MYC" in human tumours is wrong as written and must read
"weakly negatively correlated".** The only cells reading positive are the two
*sensitivity* signatures, `sig_clean` at `+0.064` / `+0.130`.

**5.2 `rho(MYC dose, ox_rel)` is NEGATIVE.** Interval excluding zero in TCGA
pooled (`-0.103`), TCGA Luminal (`-0.163`), SCAN-B pooled (`-0.048`) and SCAN-B
Luminal (`-0.043`). On `ox_lvl` it spans zero almost everywhere. **Every
activity estimator is positive throughout.**

So **"MYC-high tumours are OXPHOS-high" is an ACTIVITY statement that does not
survive being made about MYC DOSE**, and on the relative ruler dose points the
other way. **This makes D2 consequential for the H4 STATE definition**: which
estimator defines the state decides the sign of its relationship to the
respiratory axis. **Logged as a standalone finding; not acted on in E22.** It
is in `$rho_myc_ox` (5 estimators x 2 rulers x 2 cohorts x 3 strata, with
intervals) and in the script header.

## 7. THINGS THAT WILL BITE

1. **Ties break Blom scoring's equal-variance property.** SCAN-B has ties in
   `BCL2A1`, `BIK` and `PMAIP1` (**not** `BBC3`), spreading variances by
   `4.4e-4`. Scores are therefore **scaled to unit variance** after Blom
   scoring; without it the identity holds only to `~1e-4`. `$ties` carries the
   fractions.
2. **The identity is claimed for the POOLED unadjusted fit only.** Stage 2
   subsets pooled Blom scores per E19's no-re-scoring rule, which breaks equal
   variance, so it is not computed within strata. Do not extend it there.
3. **`b1_frac_lost` blows up when the unadjusted value is near zero** - 5.80 for
   TCGA dose, 36.25 for `sig_clean`. Read the raw deltas, not the fraction, for
   those rows.
4. **Never compare an adjusted value against a differently-sized unadjusted
   one.** The ladder exists so this cannot happen; if stage 3 adds a rung it
   must join the same fixed subset.
5. **N2 is untouched and must stay so.** `myc_human_validation` was not read at
   any point in E22, including for the purity provenance question, which was
   deliberately settled within-repo instead.
