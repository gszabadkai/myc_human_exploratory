# E34 - inputs, and the decisions taken before the script

**Nothing was downloaded. Nothing was written to `myc_human_validation` or
`myc_mouse`.** Nothing below is a readout. The only data touched were
missingness counts, identifier alignment and symbol resolution.

**The branch is cut from `main`, not from E33's branch.** `CLAUDE.md` says
feature branches come off `main`, and E31, E32 and E33 all did. E33 is
unmerged, so its quadrant construction and arm scoring are **copied verbatim**
into the E34 script rather than sourced from it. E34 therefore stands whether or
not E33 is ever merged.

## 1. What the declaration assumed that is not so

### 1.1 E11 defines no configuration composite

The declaration and the brief name the primary readout as "the configuration
composite, as E11 defines it". **E11 builds no per-sample composite.**
`scripts/E11_prolif_adjusted_machinery.R` was re-read for this note: it has no
`colMeans`, `scale()`, composite or configuration score. It works gene by gene
over the 44 canonical machinery genes. The figures the declaration quotes
(0.453 to 0.485, 0.187 to -0.043) are E11's summaries of those per-gene
correlations, not scores. **E33's data note had found the same thing for the
whole repo** (its section 6).

**DECISION, taken by the author on 2026-09-30 when asked before any data was
read: the primary readout is E33's signed composite, verbatim.** Each gene is
signed by its direction in the configuration (reconciliation doc, section 3.1:
"sensitisers and `BCL2L1` up, `MCL1` down"). Each score is the mean per-gene z
of log2(linear DESeq2-normalised + 1), E16's `.comp` recipe:

| readout | built as | role |
|---|---|---|
| **configuration composite** | mean(z `BBC3`, z `BID`, z `BIK`, z `BAD`, z `BCL2L1`, **-z `MCL1`**) | **PRIMARY - the verdict reads it** |
| trigger arm | mean(z `BBC3`, z `BID`, z `BIK`, z `BAD`) | reported always |
| guardian arm | mean(z `BCL2L1`, **-z `MCL1`**) | reported always |
| the twelve transcripts | each gene **unsigned**: E10's `PRIMING_PRO` (7) and `PRIMING_ANTI` (5) | reported, never the verdict; no per-gene FDR |

The z-scores are taken across each **whole cohort**: 1,095 in TCGA, as E33 did,
and 3,207 in SCAN-B. **The result note states the divergence from "as E11
defines it" in its first section.**

### 1.2 A circularity, stated before any number exists

**The configuration's genes and signs were read off OXPHOS correlations in
these same two cohorts** (reconciliation doc 3.1: "ordered by the cross-cohort
mean on OXPHOS"). A composite built from the genes most positively and most
negatively associated with OXPHOS will separate OXPHOS-high from OXPHOS-low
tumours **largely by construction**. That is independent of any biology this
analysis could reveal.

So **the two OXPHOS contrasts being positive is close to guaranteed, and it
confirms almost nothing.** The informative contrasts are the two **MYC**
contrasts: Q2 against Q4, the primary, and Q1 against Q3. Nothing forced their
size. The result note must say this whichever verdict arrives. It is one more
reason the declaration calls this confirmatory.

### 1.3 One gloss in the declaration is stronger than E33 supports

The declaration's `relates-to` says E33 found "the configuration leans MB1, as
OXPHOS does". **E33's result note did not establish that the lean is OXPHOS's.**
It declared OXPHOS-against-forkscale uninformative, and noted that the OXPHOS
lean appears on GSVA (+0.316 against +0.171) but **not on mitoPPS** (+0.197
against +0.191). The declaration is committed and is not edited. This note
records that the gloss outruns its source, and nothing in E34 depends on it.

## 2. The quadrant

### 2.1 TCGA - E33's construction, verbatim

The frozen constructor is read from
`myc_human_validation/results/state_definition.rds`: SHA-256 `a7ed4868...8ba53cad`,
integrity contract `identical(deparse(build_state), definition_source$build_state)`.

1. It must reproduce the stored `STATE_gsva` and `STATE_mitopps` exactly, from
   the stored `MYC`, `OX_*` and `BUFFER_gistic`. E33 confirmed that it does.
2. It is called a second time with `myc := oxphos` to extract its own OXPHOS
   call: same median, same `>` tie rule, same complete-case set.
3. **Q3 == level 2 exactly and Q4 == levels 3 + 4 exactly, asserted on both
   instruments. The script stops on failure.**

**Consequence, stated rather than repaired.** The frozen `STATE` takes its
complete-case set from `BUFFER_gistic`, which is `NA` for 55 patients. So those
55 have no quadrant, and the cuts are medians of **1,040**, not 1,095 - even
though the quadrant never uses BUFFER. This keeps TCGA identical to E33 and to
the frozen object, which is what reusing E33's construction means.

### 2.2 SCAN-B - the same constructor, a constant buffer

**No `STATE` exists for SCAN-B in the frozen object** (`$tcga` only). The frozen
constructor is called on SCAN-B's own inputs:

| input | source |
|---|---|
| `myc` | `results/scanb_scores.rds$gsva_new["FELSHER__MITOSTRIP", ]` - `M_a` on SCAN-B |
| `oxphos` | `$gsva_arms["OXPHOS subunits", ]` (GSVA) or `$mitopps_arms["OXPHOS subunits", ]` (mitoPPS) |
| `buffer` | **`rep(FALSE, 3207)`** - a constant |

**The buffer is constant because the quadrant does not use it.** BUFFER only
splits level 3 from level 4, and Q4 is their union. A constant buffer contributes
no `NA`, so the complete-case set is SCAN-B's own. Level 4 is therefore empty,
and level 3 is all of MYC-high OXPHOS-high. **The expression-tertile fallback
(kappa 0.221 against copy number) is not used, as the brief says.**

The constructor computes its own median from the vector it is handed, and there
is no argument through which a TCGA threshold could be passed. **The cuts are
SCAN-B's.** The same `myc := oxphos` extraction and the same two assertions
apply, against the STATE rebuilt this way.

**SCAN-B missingness**: `M_a`, both OXPHOS rulers, `FELSHER__PROLIFSTRIP` and
`PROLIF_DISJOINT` have **0 `NA`** across 3,207.

### 2.3 Instrument agreement

It is reported per cohort as the share of complete cases given the same quadrant
by GSVA and by mitoPPS (TCGA 85.0% in E33). **The verdict needs the reading rule
to hold on both.**

## 4. The models

### 4.1 Scale - Blom normal scores, pooled once per cohort

This follows E22 and E23, the repo's precedent for regressions of a transcript
readout. **Every readout and every continuous covariate is Blom
normal-scored**, `qnorm((rank - 3/8) / (n + 1/4))`, and then scaled to unit
variance, **once per cohort, over the whole cohort**. Model fits, including
within-subtype fits, **subset those scores and never re-score** (E23's rule).

Group means and contrasts are therefore in **within-cohort SD units** on a
rank-based scale. **They are never compared numerically across cohorts** (rank,
never value). The reading rule compares magnitudes **within** a cohort and
instrument only.

### 4.2 Estimation

`stats::lm`, with classical intervals, as E22 and E23 used (`sandwich` and
`emmeans` are not installed and are not needed).

- **Group estimates are standardised means**: the model's prediction averaged
  over its own analysis rows with quadrant set to q, for each q.
- Each is a linear combination of coefficients. Its 95% CI is `a' V a` with a
  t quantile on the residual df.
- **The four contrasts are differences of those means.** With no product term
  they equal coefficient differences.

**No product term anywhere.** Four group means stay four group means.

Signs are **high minus low**:

| contrast | computed as | kind | predicted |
|---|---|---|---|
| **Q2 v Q4** (primary) | Q4 - Q2 | MYC, at OXPHOS-high | no difference / much smaller |
| Q1 v Q3 (control) | Q3 - Q1 | MYC, at OXPHOS-low | no difference |
| Q1 v Q2 | Q2 - Q1 | OXPHOS, at MYC-low | positive |
| Q3 v Q4 | Q4 - Q3 | OXPHOS, at MYC-high | positive |

### 4.3 The three models, per cohort

| model | TCGA | SCAN-B |
|---|---|---|
| **m1** | readout ~ quadrant + PAM50 + purity + leukocyte fraction | readout ~ quadrant + PAM50 |
| **m2** | m1 without PAM50, **fitted within each PAM50 subtype** | readout ~ quadrant, within each subtype |
| **m3** | m1 + `PROLIF_DISJOINT` | readout ~ quadrant + PAM50 + `PROLIF_DISJOINT` |

- **SCAN-B has no purity or leukocyte estimate** (`CLAUDE.md` trap 2), so its m1
  and m2 cannot carry them. That is forced by the data, and the result note and
  figure say so.
- **PAM50** comes from `results/frames.rds`, the source E11 and E19 stratify on.
  For TCGA it is the same call E33 used from the covariate table; the only
  difference is the label `HER2` against `Her2`. `NA` in 114 TCGA and 64 SCAN-B
  patients, who drop out of every model that uses PAM50.
- Purity and leukocyte fraction: TCGA only, both present for 1,007.
- **Complete cases per model.** The n of every fit is reported.

## 5. The verdict - the rule as written, and the choices it left open

**DECISION, the author's, 2026-09-30: all three models must agree.** The rule is
applied separately in every **reading cell**:

> 2 cohorts x 2 instruments x { m1, m3, m2 within each **readable** subtype }

**DECISION, the author's: a subtype is readable in m2 only if all four quadrant
cells hold n >= 20** in that cohort and instrument. Unreadable subtypes are
still fitted where possible and reported, marked **not read**.

In each reading cell:

- **OXPHOS-ORDERED**: `Q2 - Q1` > 0 **and** `Q4 - Q3` > 0, both with 95% CIs
  excluding zero, **and** `|Q4 - Q2|` and `|Q3 - Q1|` each smaller than both
  OXPHOS contrasts.
- **MYC-DEPENDENT**: `Q4 - Q2` > 0 with its CI excluding zero, **and** "of
  comparable magnitude to the OXPHOS contrasts", operationalised here as
  **`Q4 - Q2` at least as large as the smaller of the two OXPHOS contrasts**.
  The declaration leaves "comparable" undefined. This is the exact complement of
  OXPHOS-ORDERED's magnitude clause, so no cell can be both.
- Otherwise the cell is **neither**.

**Overall verdict**: **OXPHOS-ORDERED** if every reading cell is OXPHOS-ORDERED;
**MYC-DEPENDENT** if every reading cell is MYC-DEPENDENT; **MIXED** otherwise.
That includes any disagreement between cohorts, instruments or models.

If a cohort and instrument has **no readable subtype**, m2 cannot contribute
there, and the verdict is **MIXED** for want of the declared result. This is
expected to be moot: TCGA LumA alone clears n >= 20 in every cell in E33's
counts.

**The verdict reads the configuration composite only.** The arms and the twelve
genes get the same per-cell labels in the results object, reported and never
decisive.
