## 4. Facts worth carrying

1. **The upstream cache makes the rebuild cheap and safer than expected.**
   `myc_human_validation/data/raw/tcga_brca_expression/tcga_brca_star_counts.rds`
   holds 60,660 x 1,226 **integer** counts **before** the sample filter, plus
   the GENCODE v36 annotation and the Xena SHA-256. **The log2-to-counts
   inversion is inherited, not repeated** - the most delicate upstream step is
   not re-performed.
2. **The five Xena-averaged columns are five of the six patients E33 found with
   forkscale and expression from different vials.** Same underlying fact seen
   from two directions; the sixth, `TCGA-AC-A3QQ`, is a plain vial difference.
3. **All 113 normals are matched to tumours in the analysis set.** There is no
   unmatched normal, so no unpaired analysis of them is correct.
4. **E34's analysis set of 938 is exactly Block C's 938**, patient for patient -
   checked. Different definitions, same patients. Do not read a Block C
   restriction into E34.
5. **`subset` is a base R function.** Using it as a column name in `dplyr::filter`
   compares a closure to a string and errors. E34 names that column `subtype`.
   This cost one dry run, and it failed loudly, which was lucky.
6. **The ASCII check used in earlier sessions was broken.**
   `LC_ALL=C grep -c '[^[:print:][:space:]]'` reports 0 on files containing em
   dashes under macOS BSD grep. Use `grep -P '[^\x00-\x7F]'` or a byte scan. All
   `scripts/*.R` were re-checked with a correct scan and are genuinely clean.
7. Carried from 2026-09-30 and unchanged: the aliquot-vs-patient join (E33); the
   `ecdf()` tie-block trap; `geom_label(label.size)` deprecated in ggplot2 >=
