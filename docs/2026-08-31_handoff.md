## 3. The one substantive correction so far

**E02's own size guard caught an error of mine, and it is worth remembering.**
I had transcribed `EXPECT_TANG` in E00 from `wc -l`, but the Tang CSVs carry one
row **per gene-per-evidence** - a gene with three PMIDs appears three times.

```
Ferroptosis           935 rows -> 600 genes
Autophagy_dependent  1195 rows -> 876 genes
Apoptosis             610 rows -> 608 genes
```

Counting rows overstated the large sets by up to 36%. Corrected in E00, the
cell-death README, CLAUDE.md trap 10, and E02. The two big sets are 4.8% and
3.3% of the matrix rather than 6.5% and 5% - the caution stands, smaller.
**Always count distinct genes.**

## 6. The four facts that shape everything

Each is measured, and each is in CLAUDE.md as a numbered trap.

- **Correlation is not the interaction.** The validation study's null was about
  an *interaction* on apoptotic priming. A strong MYC-OXPHOS *correlation* is
  compatible with it. Never present one as bearing on the other.
- **MYC mRNA is not MYC activity.** `rho(log2(MYC), OXPHOS subunits) = -0.032`
  against `+0.388` for the activity signature.
- **MYC does not track the mtDNA-encoded subunits.** `+0.068` against `+0.388`
  for the nuclear ones, and **negative on mitoPPS**. This is a named
  sub-analysis, not a row in a table.
- **Every MYC signature is proliferation-entangled, from 1.5% to 47.6%.** Never
  report the correlation from one signature; report the panel ordered by
  entanglement.
