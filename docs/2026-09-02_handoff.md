## 4. What E09 answered

The reading rule was written before the run: *pearson departs from spearman
while bicor sits WITH spearman -> heavy-tail artefact, Spearman is safer; bicor
with pearson -> magnitude carries information ranks discard.*

**Bicor sat with Spearman in all 12 of the largest gaps.** The disagreement is
an instrument effect and it names mitoPPS: mean |pearson - spearman| is 0.029 on
mitoPPS against 0.009 on GSVA, while bicor stays within 0.009 of Spearman on
every instrument. Kendall's apparent 0.204 max difference is pure scale -
`kendall / spearman` is 0.681 +/- 0.033 against the bivariate-normal
expectation of 0.68.

**Consequences that now bind:** report Spearman without a sensitivity caveat;
never report a Pearson against a mitoPPS score; and never say "the measures
agree" without naming the instrument, because they agree to 0.009 on GSVA and
0.029 on mitoPPS.

**Acted on 2026-09-02:** every Pearson computation and figure was removed from
`E10`. `E09` keeps its own - it is the evidence, and deleting it would delete
the reason. Nothing else in the pipeline ever computed one; E07's single
mention is a comment explaining that a partial Spearman is a Pearson on
residuals of ranks, which is correct and stays.

## 6. Traps found the hard way

Phase-2 traps 1-6 are in the scripts as comments. These are the ones added
today.

1. **A SET-LEVEL STATISTIC NEEDS A COMPOSITION-MATCHED NULL, not only an
   expression-matched one.** E10 R1 was arithmetically right and interpretively
   wrong for exactly this reason: mitochondrial genes correlate with an OXPHOS
   score whatever else they do. Whenever a finding takes the form "property X
   predicts the correlation", ask what a random set sharing X scores.
2. **An OXPHOS score correlates with much of the transcriptome.** A set can
   carry a mean |rho| of 0.27 and be doing nothing a random expression-matched
   set of its size would not do. Always report the null column, not only the
   observed one.
3. **`tibble()` evaluates its arguments in sequence and each new column shadows
   an outer object of the same name.** A column named `mitocarta` beside a data
   frame named `mitocarta` made the second reference read the logical vector.
   Rename the object, not the column.
4. **`pivot_longer(names_sep = "_")` splits on EVERY underscore.** A level named
   `adj. PROLIF_DISJOINT` produced a facet labelled `NA`. Use `names_pattern`
   anchored on the prefix you actually mean.
5. **ggplot CLIPS a caption, it does not wrap it.** Hard-wrap at about 85
   characters for an 8-9 inch figure and about 125 for a 13 inch one. `paste0`
   inserts no space, so one rendered line can be split across two source
   strings to stay inside 80 columns.
6. **Re-read every caption against the rendered image.** One said "no cross
   appears" while crosses appeared, and one said the cloud "collapses into the
   shaded band" when it visibly does not. A caption that disagrees with its own
   figure is worse than no caption.
7. **A figure's mark must mean the same thing as the caption says it does.**
   Crossing the M_b overlap on a panel that plots FELSHER was the cause of 6.
   The flag is now passed into the plot function beside its own label.
8. **E08's `canonical` column is `module`**, not `cdc_module`. E10 renames it
   only inside its own `reannot`.
9. **A scratchpad dry run leaked into `results/` and `outputs/` on 2026-09-02.**
   Those artefacts were from a superseded version of E10 and have been deleted;
   `results/` now holds only the twelve files E01-E08 produced. If a numbered
   script's output appears without you having sourced it, delete it - a partial
   object from an old version is trap 1 all over again. The dry-run harness now
   ASSERTS that its path redirection actually took effect before running, which
   is what should have caught it.
10. **Subsetting a named vector by a name it does not carry returns an element
   named `<NA>`.** `SUBMITO[CANON]` left 24 genes unnamed, the later lookup by
   symbol returned NA for all of them, `split()` dropped the NA group silently,
   and the label vector came out constant - which makes `cor()` return NA with
   a warning and no error. Every one of the eight cells read NA and the table
   still printed. `unname()` then `names(x) <- keys`, and assert on both.
11. **A statistic that can silently degenerate needs an assertion, not a
   glance.** The fix for 10 is a `stop()` when the label vector has fewer than
   two distinct values. NA in a results table is not self-announcing.

## 7. Rules that still bind

- **Option A.** Claude Code writes and edits the numbered scripts. It does not
  run them. Infrastructure - git, snapshots, provenance READMEs, `CLAUDE.md`,
  planning and result notes - it may execute directly.
- **Exploratory posture.** Nothing is pre-registered. Report structure,
  gradients and cross-cohort reproducibility; never a p-value plucked from a
  290,190-cell grid. When something looks real, write down what would falsify it
  *before* the next analysis - `E03b`, `E05b` and `E11` section 3.1 are what
  that looks like.
- **The MYC naming contract.** Every scored estimator carries `__FULL`,
  `__MITOSTRIP`, `__PROLIFSTRIP` or `__BOTHSTRIP`. There are no bare names. Use
  the `E00` constants, not string literals. `PROLIF_DISJOINT` is disjoint from
  `FELSHER__MITOSTRIP` **alone** - it shares 97 genes with the FULL panel union.
- **Never write to `myc_human_validation` or `myc_mouse`.** Read-only via
  `git -C ... show <ref>:<path>`.
- **Human only.** The ortholog tripwire is narrowed to calls:
  `grep -rnE "(mouse_to_human|human_to_mouse|ortholog[s]?)[[:space:]]*\(" scripts/`
  must return nothing.
- **Scale discipline.** GSVA wants log VST, mitoPPS wants linear DESeq2, and
  they never share an input object. Rank correlations are immune; **Pearson is
  not**, so every Pearson in E10 states its scale - log2(normalised + 1) at gene
  level against the GSVA score.
- **Never pool GSVA or mitoPPS values across cohorts.** Compare correlations and
  patterns.
- R: no `print(n = X)` after `head()`; always `dplyr::count()`; ASCII-only
  strings; every numbered script ends with an `if (FALSE) { ... }` sandbox.
- **Gene lists selected on a statistic are descriptions, not findings**, and
  must say so wherever they appear.
