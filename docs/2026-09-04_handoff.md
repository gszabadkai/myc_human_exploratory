**Added 2026-09-03 and worth knowing before the merge:** sections **3.3a** and
**3.3b**. The OXPHOS row of the ratio-gain table reads `0 of 35 in both
cohorts`, but the zero is about reproducibility, not size - the largest single

**Also added 2026-09-04, and also a handover item:** synthesis
**2.3a** and **8.4 trap 9**. The mouse's bridge ruler `ox_rel` was built here to

## 4. WHAT THE CONSOLIDATION PROMPT WILL NEED TO SETTLE

Five decisions. Each has a recommended default, so the prompt can accept them
in a line rather than answer five questions.

1. **How the mouse model arrives.** The mouse repo is **not attached** and
   CLAUDE.md keeps it read-only. *Default: paste the model into the prompt* as
   prose or propositions. If it should instead be read from the repo, the prompt
   needs **both** the ref and the paths, because the only permitted access is
   `git -C /Users/gs/G/data/MK_myc_2022/myc_mouse show <ref>:<path>`.

2. **What the deliverable is.** *Default: a new merged-model document*, leaving
   synthesis section 5 intact as the human-only statement. The human arm has to
   stay readable on its own for the paper (section 7); a merge that edits
   section 5 in place destroys that. The alternatives are an in-place rewrite of
   section 5, or a comparison table plus a decision list with no merged model.

3. **Whether new human analysis is authorised.** A merge will almost certainly
   imply human analyses - the V-list is written for exactly that. *Default:
   documents first, then a named list of implied analyses for approval before
   any script is written.* Under Option A the author sources everything in
   Positron, so a merge that silently spawns four scripts spends their time, not
   mine.

4. **What a disagreement does.** 8.3 already says what counts as agreement,
   disagreement, and neither. What it does not say is whether the merged model
   may **weaken a human proposition M1-M5**. *Default: it may, and it must say
   which one and on what evidence* - except that **N2 outranks anything
   exploratory in either arm** and cannot be merged away.

5. **Whether the output is paper-bound.** If yes, section 7's figure slots,
   statistics and language rules apply, and each merged claim should name the
   sentence or figure it feeds. If no, the merged model can stay in model
   language and skip that. *Default: not paper-bound yet* - the merge is a
   scientific step, and the paper draft follows it.

## 6. THINGS THAT WILL BITE

1. **No ortholog function anywhere, in either direction.** The reconciliation is
   a comparison of **conclusions**, not of gene lists. Tripwire:
   `grep -rnE "(mouse_to_human|human_to_mouse|ortholog[s]?)[[:space:]]*\(" scripts/`
   must stay empty.
2. **Never score SCAN-B without `scanb_pheno.rds$symbol_map`.** If a mouse model
   is projected onto SCAN-B by symbol, this breaks first and silently - coverage
   drops from 0.989 to 0.775 and Complex V loses its F1 head and c-ring.
3. **Never pool GSVA or mitoPPS values across cohorts - and a species is a
   cohort.** Compare correlations, patterns and rankings, never values.
4. **N2 outranks anything exploratory.** The sibling study is pre-registered,
   found the functional `MYC x OXPHOS` interaction on apoptotic priming null,
   and is frozen at `d3ac60e`. Nothing here overturns it and nothing may be
   written as if it did.
5. **Priming is not measurable in transcript abundance.** Write "carries a
   higher `BAD`/`MCL1` transcript ratio", never "is more primed". N3.
6. **A ratio result needs its `gain`.** In either species. 3.3, 3.3a, 3.3b.
6b. **A ruler result needs its estimator named.** In either species. Synthesis
   8.4 trap 9: `ox_rel` is the least MYC-entangled ruler on the MSigDB signature
   and the *most* on the CollecTRI regulon, in both cohorts. "The separable
   ruler" is not a property a ruler has on its own here.
6c. **`data/raw/depmap` is a SYMLINK into the closed repo, and this repo cannot
   regenerate what it points at.** `data/raw/depmap_README.md` says so and
   carries the checksums anyway. If `myc_human_validation`'s `data/raw/` is ever
   cleared, B4's input is gone from here too and the three omics files need a
   BROWSER to re-fetch - the portal is behind Cloudflare and figshare stops at
   24Q4. `E17` stops rather than skipping if the link breaks, because a broken
   symlink reads as an absent directory and script 14's idiom is to skip.
6d. **An endpoint that fails an n floor is not an endpoint that was null.**
   `E17` records every skipped fit in `$skipped` with its n and reason. The live
   case: navitoclax and venetoclax sit in a different PRISM screen from the MCL1
   compounds and cover 21-22 of the 28 lines against a floor of 25, so the only
   interpretable BCL-XL read was never fitted. Read `$skipped` before believing
   an endpoint is absent because it was null.
7. **Option A holds.** Claude Code writes and edits the numbered scripts; the
   author sources them in Positron. Infrastructure - git, snapshots, provenance
   READMEs, docs - Claude Code may do directly.
8. **The rest of the cross-species traps are synthesis 8.4** and are not
   repeated here: different MitoCarta inventories per species, the composition
   null needing a species-native rebuild, human-specific confounds, the
   non-one-to-one `Bcl2a1` paralogues, and the rule that different measurement
   types are not a disagreement.
