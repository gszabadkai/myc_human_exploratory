## 4. Lessons for the next display script

**1. Write PNGs with `type = "cairo"`.**
- The default quartz device here darkens colours. `#624E3F` is written as `#4F3D30`.
- E48's and E49's PNG previews are darkened this way; their PDFs are not.

**2. Write every PNG before any `cairo_pdf`, or use base `pdf()`.**
- In one session, PNG, then `cairo_pdf`, then PNG moves ggplot's multi-line text in the second PNG.
- Run such scripts in a freshly restarted R session.

**3. Never build a check's label from an output path.**
- The dry run redirects the paths, so such a label differs between the dry run and the real run. That is what happened to E50's row 113.

**4. For Illustrator, use base `pdf(family = "Helvetica", useDingbats = FALSE)`.**
- It writes live, editable text, as Fig. 1g's `save_panel()` does.
- Write hyphens inside words as soft hyphens, because that PDF encoding prints "-" as a minus sign.
