# Source of the E48 review pack

This folder generates `docs/2026-11-03_e48_review_pack.qmd`, which renders to
the PDF beside it. It is not a numbered script: it computes nothing from data.

**The files:**
- **`pack_text.py`** holds the result note's Part 4 text:
  - each sentence, marked as optional or not;
  - the citations for each layout (`CIT`);
  - the STYLE.md word counter, `metrics()`.

  Run it directly to print the metrics.
- **`make_pack.py`** writes the `.qmd` from `pack_text.py` and `legends.json`.
- **`legends.json`** holds the legend drafts, verbatim from
  `results/e48_separation_and_fig4g.rds` (`$legend_draft`).

**The check.** Regenerating the `.qmd` from these files reproduces the committed
one byte for byte (2026-11-03).

**After the author's decisions:**
1. Edit the sentences in `pack_text.py`.
2. Regenerate and render from the repo root:

   ```
   python3 docs/2026-11-03_e48_review_pack_src/pack_text.py
   python3 docs/2026-11-03_e48_review_pack_src/make_pack.py docs/2026-11-03_e48_review_pack_src docs/2026-11-03_e48_review_pack.qmd
   /Applications/Positron.app/Contents/Resources/app/quarto/bin/quarto render docs/2026-11-03_e48_review_pack.qmd --to typst
   ```

   The first line prints the metrics; the next two write the `.qmd` and render
   it. The render cache is gitignored.
3. Carry the same edits into Part 4 and section 4.1 of
   `docs/2026-11-03_e48_result.md`. The note's text was generated by the same
   `PARAS` list.

**The word rule.** A word is any whitespace token that contains a letter or
digit. Parenthetical figure citations and reference numbers are not counted.
